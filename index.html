📖 Как активировать на телефоне?

🤖 Для Android:
1. Скачайте приложение v2rayNG из Google Play.
2. Скопируйте ключ, сгенерированный выше.
3. Нажмите "+" сверху -> "Импортировать профиль из буфера обмена".
4. Выберите сервер и нажмите круглую кнопку подключения внизу.
🍏 Для iPhone (iOS):
1. Установите приложение v2box или Streisand из App Store.
2. Скопируйте ключ на нашем сайте.
3. Откройте вкладку Configs, нажмите "+" -> "Import from clipboard".
4. На главном экране переведите тумблер в состояние Connected.
